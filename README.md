# Fullscreen

RuneLite, but in fullscreen. **Exclusive** remains the default; automatic fullscreen on startup is optional and off by default.

Disable **Enable custom window chrome** in RuneLite settings and restart before entering fullscreen. Choose a mode and monitor in the plugin settings, or use the toolbar button or a configured hotkey. **Windowed** exits fullscreen, and the fullscreen sidebar X closes RuneLite normally.

Window placement is restored when leaving fullscreen. Interrupted fullscreen changes are detected at the next launch, which stays windowed and disables automatic entry until you enable it again.
